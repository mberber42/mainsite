# Contributing

1. Read `AGENTS.md` and the relevant `docs/<area>.md` guide.
2. Run `scripts/agent-setup.sh`.
3. Before product changes, record the existing build/test baseline or state why no baseline is available.
4. Stay within the assigned phase. Add/update tests for behavior changes and avoid unsupported personal claims.
5. Run `npm run lint`, `npm test`, `npm run format:check`, and `npm run build` before opening a PR.
6. Include a concise summary, exact test commands and results, risks/follow-ups, and requested screenshots in the PR description.
7. Never push to `main` or `release`, merge, or deploy.
